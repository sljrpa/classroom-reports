高三零轮 直线与圆复习课 教学设计（第二课时）

一、教材分析

本节复习课属于高三零轮复习解析几何板块的第二课时，承接第一节课直线方程与距离公式的基础，聚焦圆的方程、直线与圆的位置关系、切线问题、弦长问题以及圆与圆的位置关系。圆的方程（标准式与一般式）是解析几何中"曲线方程"概念的入门载体，而直线与圆的位置关系则是后续圆锥曲线研究的基础模型。

二、学情分析

学生在上一节课中已掌握直线方程的四种形式及其适用范围，独立推导了中点坐标公式、两点间距离公式和点到直线距离公式，并辨析了垂直条件的两种表达。第一节课的教学反思显示：学生处理速度尚可，但普遍存在"代公式不画图"的问题，同时也有个别学生开始尝试用画图方式解决问题。

基于此，本节第二课时以"从图像出发分析问题"为核心要求，通过讲题强化数形结合思想。

三、教学目标

  1. 掌握圆的定义，能从定义出发推导圆的标准方程。
  2. 会从圆的标准方程和一般方程中推导出圆心坐标和半径，理解一般方程的适用条件。
  3. 掌握判断直线与圆位置关系的两种方式：几何法（d 与 r 比较）和代数法（联立方程判别式 Δ）。
  4. 会求切线方程（过圆上点的切线、过圆外点的切线）。
  5. 会求弦长（利用圆心到直线距离 d 与半径 r 的关系）。
  6. 会设计运算程序判断圆与圆的位置关系（比较圆心距与半径之和、半径之差）。
  7. 养成"先画图，再列式，最后计算"的解题习惯，强化数形结合思想。

四、教学重难点

重点：圆的方程（标准式与一般式）；直线与圆位置关系的两种判断方式；切线与弦长的求法。

难点：能够从图像出发分析和解决问题，而不是单纯依赖公式计算；圆与圆位置关系运算程序的设计。

五、教学过程

第 一 课 时

环节一：圆的定义与标准方程（教师引领）

教师引领提问驱动，学生跟答

教师从圆的基本定义出发，逐步引导学生推导出圆的标准方程。通过提问让学生自己说出每一步的依据。

（一）圆的定义

▶ 定义

平面内到定点的距离等于定长的点的集合叫做圆。

定点 → 圆心，定长 → 半径。

师："圆的定义和直线一样，都是用'条件'来约束点的轨迹。不同的是，直线用'一个点+一个方向'，圆用'一个点+一个距离'。请大家思考：从定义出发，怎么把'到定点距离等于定长'这个条件翻译成代数方程？"

（二）由定义推导圆的标准方程

▶ 推导过程

设圆心为 C(a, b)，半径为 r，P(x, y) 是圆上任意一点。

由定义：|PC| = r，即 √[(x−a)² + (y−b)²] = r

两边平方：(x − a)² + (y − b)² = r²

这就是圆的标准方程。

核心：圆的标准方程直接给出了圆心 (a, b) 和半径 r。看到标准方程，立刻就能读出圆心和半径。

环节二：圆的一般方程（小组讨论）

小组讨论学生自主探究一般方程

各组将标准方程展开，推导一般方程的形式，并讨论：什么条件下一般方程才表示一个圆？这个条件从哪里来？

（一）一般方程的推导

将标准方程 (x − a)² + (y − b)² = r² 展开：

x² + y² − 2ax − 2by + a² + b² − r² = 0

令 D = −2a，E = −2b，F = a² + b² − r²，得到：

x² + y² + Dx + Ey + F = 0

（二）适用条件——学生补充

📝 讨论要点：条件 D² + E² − 4F > 0 从何而来？

引导学生将一般方程配方回标准形式：

(x + D/2)² + (y + E/2)² = (D² + E² − 4F) / 4

右边必须大于 0，即 D² + E² − 4F > 0，此时：

圆心 = (−D/2, −E/2)，半径 r = √(D² + E² − 4F) / 2

标准方程 ↔ 一般方程：互转的关键是配方。标准方程直接读出圆心和半径；一般方程需要配方，且必须满足 D² + E² − 4F > 0。

环节三：直线与圆的位置关系（小组讨论）

小组讨论两种判断方式

各组讨论：已知直线和圆的方程，如何判断它们的位置关系？要求用两种方法，并比较各自的优缺点。

位置关系几何特征代数特征
相离直线与圆没有交点联立方程组无实数解（Δ < 0）
相切直线与圆恰好有 1 个交点联立方程组有唯一实数解（Δ = 0）
相交直线与圆有 2 个交点联立方程组有两个实数解（Δ > 0）

方法一：几何法（d 与 r 比较）

▶ 判断方法

求圆心到直线的距离 d，与半径 r 比较：

d > r → 相离；d = r → 相切；d < r → 相交。

d = |Ax₀ + By₀ + C| / √(A² + B²)

方法二：代数法（判别式 Δ）

▶ 判断方法

将直线方程代入圆的方程，消去一个变量后得到一元二次方程，计算判别式 Δ：

Δ > 0 → 相交；Δ = 0 → 相切；Δ < 0 → 相离。

两种方法各有适用场景：几何法运算量小，适合快速判断位置关系和求弦长；代数法更通用，适合需要求具体交点坐标的场景。优先使用几何法。

环节四：圆与圆的位置关系（小组讨论）

小组讨论设计运算程序

各组讨论：已知两个圆的方程，如何判断它们的位置关系？请设计一个完整的"运算程序"（判断步骤）。

▶ 运算程序

步骤 1：将两圆方程化为标准形式，分别得到圆心 C₁、C₂ 和半径 r₁、r₂。

步骤 2：计算圆心距 d = |C₁C₂| = √[(x₂−x₁)² + (y₂−y₁)²]

步骤 3：比较 d 与 r₁+r₂、|r₁−r₂| 的大小关系：

位置关系条件几何特征
外离d > r₁ + r₂两圆没有公共点
外切d = r₁ + r₂两圆有 1 个公共点（外切点）
相交|r₁ − r₂| < d < r₁ + r₂两圆有 2 个公共点
内切d = |r₁ − r₂|两圆有 1 个公共点（内切点）
内含d < |r₁ − r₂|两圆没有公共点

师："注意：圆与圆有 5 种位置关系，比直线与圆多了 2 种。关键在于先算圆心距，再和两个'门槛值'比较。画个图一看就清楚。"

环节五：过圆外一点求切线（小组讨论）

小组讨论切线方程的求法

各组讨论：已知圆外一点 P，如何求过 P 向圆所作的切线方程？

▶ 方法

已知圆 C：(x−a)² + (y−b)² = r²，圆外一点 P(x₀, y₀)。

思路：设切线斜率为 k，切线方程为 y − y₀ = k(x − x₀)。

关键条件：圆心到切线的距离等于半径，即：

|k(a − x₀) + (y₀ − b)| / √(k² + 1) = r

解此方程得 k，再写切线方程。

⚠ 注意

① 斜率不存在的情况需单独验证（竖直线是否为切线）。

② 过圆外一点通常有两条切线，解方程时注意不要漏解。

核心思想：切线 ⊥ 半径。利用"圆心到切线的距离 = 半径"这一几何条件列方程，比用判别式 Δ = 0 更简洁。

题目一（原第 5 题）——圆上点到直线的距离最值

题目

已知点 P 在圆 (x+1)² + y² = 2 上，则 P 到直线 x + y − 5 = 0 距离的最小值为（ ）

▶ 解题思路（几何法）

画图：圆心 C(−1, 0)，半径 r = √2。在坐标系中画出圆和直线。

列式：圆心到直线的距离 d = |−1 + 0 − 5| / √(1+1) = 6/√2 = 3√2

因为 d > r（3√2 > √2），直线在圆外，所以：

dmin = d − r = 3√2 − √2 = 2√2

题目二（原第 7 题）——圆与坐标轴相切

题目

若过点 (2, 1) 的圆与两坐标轴都相切，则圆心到直线 2x − y − 3 = 0 的距离为（ ）

▶ 解题思路

画图：圆与两坐标轴都相切，且过 (2, 1)（第一象限），所以圆心在第一象限，且圆心坐标为 (r, r)。

列式：由 (r, r) 到 (2, 1) 的距离等于 r：

(r − 2)² + (r − 1)² = r²

展开：r² − 6r + 5 = 0，解得 r = 1 或 r = 5。

计算：

当 r = 1，圆心 (1, 1)，d = |2−1−3|/√5 = 2/√5 = 2√5/5（选项 B）

当 r = 5，圆心 (5, 5)，d = |10−5−3|/√5 = 2/√5 = 2√5/5（选项 B）

题目

题目四（原第 17 题）——弦长求参数

题目

若直线 x − y + m = 0（m > 0）被圆 (x−1)² + (y−1)² = 3 截得的弦长为 m，则 m 的值为______。

▶ 解题思路

圆心 (1, 1)，半径 r = √3。

列式：圆心到直线距离 d = |1 − 1 + m| / √2 = m/√2

弦长公式：弦长 = 2√(r² − d²) = 2√(3 − m²/2)

令弦长 = m：

2√(3 − m²/2) = m

两边平方：4(3 − m²/2) = m² → 12 − 2m² = m² → m² = 4 → m = 2（m > 0）

答案：m = 2

题目五（原第 18 题）——弦长与半径

题目

已知直线 x − √3 y + 8 = 0 与圆 x² + y² = r²（r > 0）相交于 A、B 两点。若 |AB| = 6，则 r 的值为______。

▶ 解题思路

圆心 (0, 0)，半径 r。

列式：圆心到直线距离 d = |0 − 0 + 8| / √(1+3) = 8/2 = 4

弦长公式：|AB| = 2√(r² − d²)

6 = 2√(r² − 16) → 3 = √(r² − 16) → 9 = r² − 16 → r² = 25

答案：r = 5

题目六（原第 19 题）——切线条件确定圆

题目

已知圆 C 的圆心坐标是 (0, m)，半径长是 r。若直线 2x − y + 3 = 0 与圆 C 相切于点 A(−2, −1)，则 m = ______，r = ______。

▶ 解题思路

条件一：A(−2, −1) 在圆上 → (−2)² + (−1 − m)² = r²，即 4 + (1+m)² = r²

条件二：圆与直线相切 → 圆心到直线距离 = r：

|2·0 − m + 3| / √5 = r，即 r = |3 − m| / √5，r² = (3−m)² / 5

联立：

4 + (1+m)² = (3−m)² / 5

展开：5[4 + 1 + 2m + m²] = 9 − 6m + m²

25 + 10m + 5m² = 9 − 6m + m²

4m² + 16m + 16 = 0 → m² + 4m + 4 = 0 → (m+2)² = 0

答案：m = −2，r² = 25/5 = 5，r = √5

七、教学反思

（一）学生不会画图结合图像——核心问题

第一节课反思中已指出"学生总在代公式不画图"，第二节课通过 6 道习题的讲题进一步强化了这一观察。大部分学生在解题时仍然习惯直接代入公式，而不先画草图建立直观感知。

典型表现：

① 求圆上点到直线距离最值时，不画图就不知道应该用"圆心距 − 半径"的几何思路；

② 圆与坐标轴相切的问题，不画图就难以判断圆心位置和半径的关系；

③ 弦长问题中，不画图就不知道该用"半弦长²+ d² = r²"的几何关系。

⚠ 后续改进方向

后续教学中必须持续狠抓"先画图再列式"的解题习惯。每道解析几何题，要求学生第一步先画坐标系和草图，标注已知信息（圆心、半径、直线位置、关键点），建立直观感知后再列式计算。

（二）画图时斜率出错——图形意识薄弱的具体表现

虽然很多学生开始意识到要画图，但画出来的图经常不对，尤其是直线的位置——斜率经常画错。例如看到方程 x − y + 3 = 0，画出的直线斜率与实际不符；看到 x − √3 y + 8 = 0，无法快速判断直线的倾斜方向和陡峭程度。

这说明学生的"画图"只是形式上的画，缺乏对方程与图像对应关系的基本敏感度。后续需要专门训练"看方程画直线"的基本功：先求斜率、再定截距、最后标注关键点。

（三）过度依赖弦长公式——忽视更简洁的勾股定理

涉及弦长问题时，学生普遍习惯直接套弦长公式 弦长 = 2√(r² − d²)，但在很多情况下，直接用勾股定理（半弦长² + d² = r²）更简洁。弦长公式本身就是从勾股定理推出来的，学生记住了公式却忘了本源，反而增加了一步不必要的代入和化简。

⚠ 后续改进方向

在讲题时强调：半弦长、圆心到直线距离 d、半径 r 构成直角三角形，三者的关系就是勾股定理。能直接用勾股定理解决的，不必套弦长公式。减少一层公式包装，运算量更小、出错率更低。

（四）学生亮点——从图像出发解题的尝试

学生班级精彩表现

李炫增的画图解法和马铄的参数方程方法，说明班上已有学生开始具备"从图像出发"和"灵活迁移知识"的意识。这和第一节课"学生总在代公式不画图"形成了鲜明对比——进步是可见的，但只是少数。后续需要把这种图像思维推广到更多学生身上。
