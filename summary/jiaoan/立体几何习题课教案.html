高三零轮 立体几何习题课 教学设计

一、教材分析

本节习题课基于学生已完成的"立体几何水平0"测试卷，聚焦两个核心题型——求空间角与求几何体体积。通过精选例题，系统梳理求夹角的三条路径（定义法→三角形法→向量法）和求体积的三个方案（换顶点→割补法→向量法），帮助学生建立从几何直观到代数工具的完整解题框架。

二、学情分析

本节处于高三零轮复习阶段。学生在概念复习课中已系统梳理了空间几何体的结构、公式与定理，具备基本的空间想象能力。零轮复习的目标不是全面重讲知识点，而是帮助学生从"知道概念"过渡到"会用方法解题"，建立方法选择的自觉意识。但在面对具体计算题时，主要困难在于：① 线面角、二面角的定义理解停留在"知道"层面，实际找角操作不熟练；② 求体积时缺乏系统的方法选择意识，容易陷入"不知道该用哪种方法"的困境。本节课通过"定义铺垫→方法归纳→例题演练"的链条，帮助学生将知识转化为解题能力，为后续一轮复习做好方法和思维上的准备。

三、教学目标

  1. 准确理解线面角和二面角的定义，能独立完成"找垂足→连投影→定夹角"的操作步骤
  2. 掌握求空间夹角的三条路径，能根据题目特点灵活选择定义法、三角形法或向量法
  3. 掌握求几何体体积的三个方案（换顶点、割补法、向量法），能在长方体/正方体情境中熟练运用
  4. 通过一题多解，体会不同方法的优势与局限，形成方法选择的自觉意识

四、教学重难点

重点：线面角与二面角的定义操作；求夹角的三条路径与求体积的三个方案

难点：二面角定义中"垂足重合"的认知冲突与解决；根据题目特征灵活选择最优解法

五、教学过程

环节一：概念铺垫——两个核心定义

（一）线面角的定义与操作

线面角的定义：一条斜线与它在平面内的射影所成的锐角，叫做这条直线与这个平面所成的角。

找线面角的关键三步（板书）：

  1. 找垂足——过斜线上一点向平面作垂线，垂足为 H
  2. 连投影——连接垂足 H 与斜足 A，得到斜线在平面内的射影 HA
  3. 定夹角——斜线与射影 HA 的夹角 SAH 即为线面角

示范：长方体中的线面角

在长方体 ABCD-A₁B₁C₁D₁ 中，体对角线 AC₁ 与左侧面 ADD₁A₁ 所成的角。

教师示范：过 C₁ 向左侧面 ADD₁A₁ 作垂线，垂足为 D₁（因为 C₁D₁ 面 ADD₁A₁）。连接 D₁ 与斜足 A，得到射影 AD₁。则 AC₁ 与左侧面所成角为 ∠C₁AD₁。

📝 学生活动

任务：请学生自己搭一个——体对角线 AC₁ 与前面 ABB₁A₁ 所成的角。

预期操作：过 C₁ 向前面 ABB₁A₁ 作垂线，垂足为 B₁（因为 C₁B₁ ⊥ 面 ABB₁A₁）。连接 B₁ 与斜足 A，得到射影 AB₁。则 AC₁ 与前面所成角为 ∠C₁AB₁。

（二）二面角的定义与认知冲突

二面角的定义：从一条直线出发的两个半平面所组成的图形叫做二面角。这条直线叫做二面角的棱，这两个半平面叫做二面角的面。

二面角的平面角：在二面角的棱上任取一点，在两个面内分别作垂直于棱的两条射线，这两条射线所成的角叫做二面角的平面角。

找二面角平面角的关键三步（板书）：

  1. 找交线（棱）——确定两个半平面的公共直线
  2. 作垂线——在两个面内各作一条垂直于交线的射线
  3. 定夹角——两条垂线所成的角即为二面角的平面角

探究：正四面体中的二面角

在正四面体 ABCD 中，求二面角 A-BC-D 的平面角。

操作步骤：

① 找交线：BC 是面 ABC 与面 DBC 的交线（棱）。

② 作垂线：过 A 作 BC 的垂线，垂足为 M；过 D 作 BC 的垂线，垂足为 N。

📝 认知冲突

问题：在正四面体中，过 A 作 BC 的垂线，垂足 M 是 BC 的中点（因为 △ABC 是等边三角形）；过 D 作 BC 的垂线，垂足 N 也是 BC 的中点。

意外情况：M 和 N 恰好重合！那么 AM 和 DM 都在各自的面内且垂直于 BC，∠AMD 就是二面角 A-BC-D 的平面角。

追问：如果不是正四面体呢？如果 M 和 N 不重合怎么办？找不到同一个点上的两条垂线，这个角怎么找？

师：这就是定义法的局限——当两个面内的垂足不重合时，我们无法直接在棱上找到一个点同时作出两条垂线。这就引出了我们的核心问题：定义法找到了角的位置，但算不出来，怎么办？今天这节课，我们就来系统解决这个问题。

环节二：求夹角——三条路径

面对"求空间夹角"的问题，我们有三条路径可选：

路径方法适用场景优势
路径①定义法：找到角→放入三角形→用余弦定理或特殊三角形关系求解角的位置容易确定，三角形信息充分几何直观强
路径②三角形法：将角归入某个三角形，利用边角关系（余弦定理/正弦定理/特殊三角形）能构造出含目标角的三角形计算量适中
路径③向量法：建立坐标系→求方向向量/法向量→用向量夹角公式定义法找不到角或计算复杂时万能、机械化

方法选择的逻辑：先用定义法"找到角在哪里"——如果角的位置清晰且三角形信息充分，直接在三角形中用余弦定理求解；如果定义法卡住了（如垂足不重合、三角形信息不足），再切换到向量法。向量法是兜底的万能工具，但计算量较大，优先用几何方法。

（一）例题：定义法 + 向量法双解（题14）

题14：若四面体棱长都相等，则相邻两侧面所成的二面角的余弦值为 （　　）

A. 1/4　　B. 1/3　　C. 1/2　　D. 2/3

路径① 定义法

设正四面体棱长为 a。

① 找交线：设所求二面角为面 ABC 与面 DBC 所成，交线为 BC。

② 作垂线：在等边 △ABC 中，过 A 作 BC 的垂线，垂足 M 为 BC 中点，AM = (√3/2)a。在等边 △DBC 中，过 D 作 BC 的垂线，垂足 N 为 BC 中点，DN = (√3/2)a。

关键：由于正四面体的对称性，M 与 N 重合于 BC 中点，因此 ∠AMD 即为二面角 A-BC-D 的平面角。

③ 放入三角形求解：在 △AMD 中，AM = DM = (√3/2)a，AD = a。

由余弦定理：

cos∠AMD = (AM² + DM² − AD²) / (2 · AM · DM)

= (3a²/4 + 3a²/4 − a²) / (2 · 3a²/4)

= (a²/2) / (3a²/2) = 1/3

✓ 答案：B（1/3）

路径 向量法

建系：以 BC 中点 M 为原点，BC 方向为 x 轴，MA 方向为 y 轴，建立空间直角坐标系。

点坐标
B(−a/2, 0, 0)
C(a/2, 0, 0)
A(0, √3a/2, 0)
D(0, √3a/6, √6a/3)

求法向量：

面 ABC 在 xy 平面内，法向量 n₁ = (0, 0, 1)。

面 DBC 中：MB⃗ = (−a/2, 0, 0)，MD⃗ = (0, √3a/6, √6a/3)

n₂ = MB⃗ × MD⃗ = (0, √6a²/6, −√3a²/12)，取 n₂ = (0, 2√6, −√3)（化简方向）。

求夹角：

cos θ = |n₁ · n₂| / (|n₁| · |n₂|) = √3 / (24 + 3) = √3/√27 = 1/3

✓ 两种方法均得 cos θ = 1/3，答案 B。

师：定义法的优势在于几何直观——我们"看到"了角在哪里；向量法的优势在于机械化操作——不需要找垂足，只需要建系算坐标。两种方法互相验证，结果一致，说明我们对二面角的理解是正确的。

（二）例题：向量法求异面直线夹角（题13）

题13：在长方体 ABCD-A₁B₁C₁D₁ 中，AB = BC = 1，AA₁ = √3，则异面直线 AD₁ 与 DB₁ 所成角的余弦值为 （　　）

A. 1/5　　B. √5/6　　C. √5/5　　D. √2/2

路径③ 向量法

建系：以 D 为原点，DA、DC、DD₁ 分别为 x、y、z 轴。

点坐标
D(0, 0, 0)
A(1, 0, 0)
B₁(1, 1, √3)
D₁(0, 0, √3)

求方向向量：

AD₁⃗ = D₁ − A = (−1, 0, √3)

DB₁⃗ = B₁ − D = (1, 1, √3)

求夹角：

AD₁⃗ · DB₁ = (−1)(1) + 0·1 + √3·√3 = −1 + 0 + 3 = 2

|AD₁⃗| = √(1 + 0 + 3) = 2

|DB₁| = √(1 + 1 + 3) = √5

cos θ = |AD₁⃗ · DB₁⃗| / (|AD₁⃗| · |DB₁⃗|) = 2 / (2√5) = √5/5

✓ 答案：C（√5/5）

师：异面直线夹角用定义法很难直接"找到角"，因为它们不相交。向量法在这里体现了巨大优势——只需要把两条直线的方向向量求出来，代入夹角公式即可。这就是向量法作为"万能工具"的价值。

（三）例题：向量法求线线角（题15）

题15：在正方体 ABCD-A₁B₁C₁D₁ 中，P 为 B₁D₁ 的中点，则直线 PB 与 AD₁ 所成的角为 （　　）

A. π/2　　B. π/3　　C. π/4　　D. π/6

路径③ 向量法

建系：设棱长为 2（便于计算中点），以 A 为原点，AB、AD、AA₁ 分别为 x、y、z 轴。

点坐标
A(0, 0, 0)
B(2, 0, 0)
D₁(0, 2, 2)
B₁(2, 0, 2)
D₁(0, 2, 2)
P（B₁D₁中点）(1, 1, 2)

求方向向量：

PB = B − P = (1, −1, −2)

AD₁⃗ = D₁ − A = (0, 2, 2)

求夹角：

PB⃗ · AD₁⃗ = 1·0 + (−1)·2 + (−2)·2 = 0 − 2 − 4 = −6

|PB⃗| = √(1 + 1 + 4) = 6

|AD₁⃗| = √(0 + 4 + 4) = 2√2

cos θ = |PB⃗ · AD₁| / (|PB⃗| · |AD₁⃗|) = 6 / (√6 · 2√2) = 6 / (2√12) = 6 / (4√3) = √3/2

✓ cos θ = √3/2，θ = π/6，答案：D

（四）高考真题：向量法求线面角（2020北京卷）

2020北京卷：在正方体 ABCD-A₁B₁C₁D₁ 中，E 为 DD₁ 的中点。求直线 BE 与平面 CDE 所成角的正弦值。

向量法

建系：设正方体棱长为 2，以 D 为原点，DA、DC、DD₁ 分别为 x、y、z 轴。

点坐标
D(0, 0, 0)
C(0, 2, 0)
B(2, 2, 0)
E（DD₁中点）(0, 0, 1)

求平面 CDE 的法向量：

DC⃗ = (0, 2, 0)，DE⃗ = (0, 0, 1)

n⃗ = DC⃗ × DE⃗ = (2, 0, 0)，取 n⃗ = (1, 0, 0)

求线面角：

BE⃗ = E − B = (−2, −2, 1)，|BE⃗| = 3

sin θ = |BE⃗ · n⃗| / (|BE⃗| · |n⃗|) = 2 / (3 × 1) = 2/3

✓ 直线 BE 与平面 CDE 所成角的正弦值为 2/3。

师：这道北京卷的题是典型的"建系友好型"——正方体天然提供三条互相垂直的棱，建系非常直接。法向量恰好沿 x 轴方向，计算量很小。同学们在考场上遇到正方体、长方体模型时，应优先考虑向量法。

环节三：求体积——三个方案

面对"求几何体体积"的问题，我们有三个方案：

方案方法适用场景核心思路
方案①换顶点（等体积变换）原顶点到底面的距离不好求换一个"好算"的顶点，底面积和高都容易确定
方案②割补法几何体嵌在长方体/正方体内用整体体积减去多余部分的体积
方案③向量法坐标已知，直接计算利用混合积公式 V = (1/6)|AB⃗ · (AC⃗ × AD⃗)|

方法选择的逻辑：先看几何体是否嵌在规则体（长方体/正方体）内——如果是，优先考虑割补法；如果顶点和底面都清晰，但高不好求，尝试换顶点；如果坐标已经建立或容易建立，直接用向量法。

（一）例题：换顶点法（题22）

题22：如图，长方体 ABCD-A₁B₁C₁D₁ 的体积是 120，E 为 CC₁ 的中点，则三棱锥 E-BCD 的体积是 ______。

方案① 换顶点

分析：直接求三棱锥 E-BCD 的体积，需要知道 △BCD 的面积和 E 到面 BCD 的距离。

观察：面 BCD 就是长方体的底面 ABCD 的一部分（△BCD 在底面上）。E 在 CC₁ 上，E 到底面的距离 = EC = CC₁/2。

设 AB = a，BC = b，CC₁ = c，则 abc = 120。

计算：

S△BCD = (1/2) · BC · CD = (1/2) · b · a = ab/2

h = EC = c/2

VE-BCD = (1/3) · S△BCD · h = (1/3) · (ab/2) · (c/2) = abc/12

VE-BCD = 120/12 = 10

✓ 三棱锥 E-BCD 的体积为 10。

师：换顶点的本质是"等体积变换"——同一个三棱锥，换不同的顶点看，体积不变，但计算的难易程度可能完全不同。选择"好算"的顶点，就是选择底面积和高都容易确定的那个组合。

（二）例题：割补法 + 向量法双解（题23）

题23：已知正方体 ABCD-A₁B₁C₁D₁ 的棱长为 2，M、N 分别为 BB₁、AB 的中点，则三棱锥 A-NMD₁ 的体积为 ______。

方案② 割补法

思路：三棱锥 A-NMD₁ 嵌在正方体内，用正方体体积减去周围四个三棱锥的体积。

正方体体积 V = 2³ = 8。

需要减去的四个三棱锥：

三棱锥底面积高体积
A₁-AN D₁S = (1/2)·AN·A₁D₁ = (1/2)·1·2 = 1h = AA₁ = 2V₁ = (1/3)·1·2 = 2/3
B-NBM（即B-NM...）需仔细分析各顶点位置

割补法需要仔细识别正方体中"剩余部分"的几何结构，操作较繁琐。下面用向量法直接计算，更为简洁。

方案③ 向量法

建系：以 A 为原点，AB、AD、AA₁ 分别为 x、y、z 轴。

点坐标
A(0, 0, 0)
N（AB中点）(1, 0, 0)
M（BB₁中点）(2, 0, 1)
D₁(0, 2, 2)

从顶点 A 出发的三条棱向量：

AN⃗ = (1, 0, 0)

AM⃗ = (2, 0, 1)

AD₁⃗ = (0, 2, 2)

混合积公式：

V = (1/6) |AN · (AM⃗ × AD₁)|

先算叉积：

AM⃗ × AD₁ = |i j k; 2 0 1; 0 2 2| = i(0·2 − 1·2) − j(2·2 − 1·0) + k(2·2 − 0·0)

= (−2, −4, 4)

再算点积：

AN⃗ · (AM⃗ × AD₁⃗) = (1, 0, 0) · (−2, −4, 4) = −2

最终：

V = (1/6) · |−2| = 1/3

✓ 三棱锥 A-NMD₁ 的体积为 1/3。

师：向量法在这里的优势非常明显——不需要分析复杂的几何关系，只需要写出四个点的坐标，代入混合积公式一步到位。割补法虽然几何直观，但需要仔细识别"减去哪些部分"，容易出错。两种方法可以互相验证。

（三）高考真题：综合应用（2020全国二卷文）

2020全国二卷（文）：已知三棱柱 ABC-A₁B₁C₁ 的底面是正三角形，侧面 BB₁C₁C 是矩形，M、N 分别为 BC、B₁C₁ 的中点，P 为 AM 上一点。过 B₁C₁ 和 P 的平面交 AB 于 E，交 AC 于 F。

设 O 为 △A₁B₁C₁ 的中心，若 AO = AB = 6，AO ∥ 平面 EB₁C₁F，且 ∠MPN = π/3，求四棱锥 B-EB₁C₁F 的体积。

方案①② 综合分析

关键几何关系梳理：

  • 底面 △ABC 是边长为 6 的正三角形，M 为 BC 中点，AM = 3√3
  • 侧面 BB₁C₁C 是矩形，BC ⊥ BB₁，又 BC ⊥ AM，故 BC ⊥ 平面 A₁AMN
  • 由 AO ∥ 平面 EB₁C₁F 可推出 AP = ON = 3，PM = 3√3 − 3

求体积：由于 BC ⊥ 平面 A₁AMN，而平面 EB₁C₁F ⊂ 平面 A₁AMN，可以利用这一垂直关系简化体积计算。

VB-EB₁C₁F = 1/3 × SEB₁C₁F × h

其中 SEB₁C₁F 为梯形面积，h 为 B 到截面的距离。由混合积公式可直接计算：

V = 1/6 |BE⃗ · (BB₁⃗ × BC⃗)| = 27/2

✓ 四棱锥 B-EB₁C₁F 的体积为 27/2。

师：这道全国卷的题综合性很强——第一步要证明面面垂直，第二步才求体积。关键突破口是发现 BC ⊥ 平面 A₁AMN，这既是第一问的证明目标，也是第二问求体积的几何基础。这再次验证了我们反复强调的：第一问的证明往往在为第二问的计算铺路。

（四）方法对比与总结

▶ 求空间夹角的三条路径

路径① 定义法：找到角 → 放入三角形 → 余弦定理/特殊三角形关系求解。几何直观强，但角的位置不好找时卡住。

路径② 三角形法：将角归入三角形，利用边角关系。需要能构造出含目标角的三角形。

路径③ 向量法：建系 → 求方向向量/法向量 → 向量夹角公式。万能工具，机械化操作，计算量较大。

选择策略：优先尝试定义法/三角形法（几何直观），卡住时切换向量法（万能兜底）。

▶ 求几何体体积的三个方案

方案① 换顶点：等体积变换，换一个好算的顶点，使底面积和高都容易确定。

方案② 割补法：几何体嵌在规则体内时，用整体减去多余部分。几何直观强，但需仔细分析结构。

方案③ 向量法：建系后利用混合积公式 V = (1/6)|AB⃗ · (AC⃗ × AD⃗)| 直接计算。简洁高效。

（一）整体设计回顾

（二）课堂上暴露的核心问题

问题一：几何体观察能力薄弱——分不清"谁是底、谁是高"

学生从"水平零"测试突然进入立体几何部分，对几何体的空间结构观察很不熟练。典型表现：

以第10题为例：底面是正方体的体对角面（矩形），但"高在哪里"学生产生了明显困难。更深层的问题在于，教师讲解"为什么这条线是高"时，学生对线面垂直的推导过程反应也很弱——说明线面垂直的判定定理在学生的认知中并未形成可迁移的能力。

→ 改进方向：在复习课开始阶段，需增加"识别底面与高"的专项训练，尤其是非标准摆放的几何体；同时线面垂直的判定逻辑需作为前置知识反复强化。

问题二：割补法思维缺乏主动性

涉及"某锥体占正方体/长方体的几分之几"这类题目时，学生没有主动想到用割补法去思考。即使在教师提示"可以考虑用整体减去多余部分"之后，学生的反应也比较慢，说明割补法的思维习惯尚未建立。

→ 改进方向：在求体积的教学中，应将割补法作为"看到正方体/长方体中的锥体"时的默认策略明确告诉学生，并通过2-3道对比题形成条件反射。

问题三：体积比例的直觉误判——"看起来像一半"

以正三棱柱中三棱锥 A₁-ABC 为例：其体积占整个三棱柱的比例，学生凭视觉感受普遍认为是 1/2，但实际答案是 1/3。

原因分析：三棱柱去掉三棱锥 A₁-ABC 后，剩下的部分是一个四棱锥（而非"对称的另一半"），因此三棱锥体积 ≠ 三棱柱的一半。这是一个典型的"视觉直觉与数学推理不一致"的案例。

备注：此问题在二班首次发现后，在授课时在一班做了有针对性的引导，效果有所改善。

→ 改进方向：教学中要专门设计"打破直觉"的对比环节，让学生先用直觉猜、再用公式算，通过认知冲突强化正确理解。

问题四（未预料到的生成性问题）：转底法的适用边界

学生在分析体积比例时，出现了两个关于"转底法"的典型错误，这是课前未预料到的：

案例1（王浩明）：尝试用正三棱柱的侧面当底面积、正三角形的高当高来计算三棱锥 A₁-ABC 的体积比例，得出 1/12（而非 1/6）。根本原因：三棱柱不能拿侧面当底面积——如果拿侧面当底、对应高计算，求出来的是外接长方体的体积，而不是三棱柱本身的体积。

案例2（孙林博，一班讲第10题）：认为"四棱锥可以转底面"。实际上，四棱锥不能随意转底面——转底后必须能确定新底面对应的高，否则转底法不成立。

→ 改进方向：需要在教学中明确"转底法"的适用条件——三棱锥可以转底（任意面当底+对应高可确定），但棱柱不能拿侧面当底，四棱锥转底有条件限制（新底面必须能确定对应高）。建议专门设计一节微课或板书对比表，厘清转底法的适用边界。
